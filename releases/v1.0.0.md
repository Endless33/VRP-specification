# VRP Specification

## Release v1.0.0

Release Date: August 2026

Status: Initial Public Release

---

# Overview

Version 1.0.0 represents the first complete public engineering specification of the Veil Routing Protocol (VRP).

This release establishes the architectural foundation of VRP and defines the public engineering contract for independent evaluation.

The Protected Runtime implementation remains outside the scope of this release.
