# Evidence Before Claims

## Purpose

This document explains one of the core engineering principles behind the Veil Routing Protocol (VRP):

**Evidence Before Claims.**

It describes why engineering conclusions should be supported by observable, reproducible evidence rather than assumptions, reputation or marketing.

---

# Engineering Requires Verification

Engineering should not depend upon:

- promises
- assumptions
- expectations
- reputation
- authority

Engineering should depend upon observable behavior.

---

# Claims Must Be Testable

Every meaningful engineering claim should be capable of independent evaluation.

Engineering teams should be able to verify:

- deterministic behavior
- recovery behavior
- architectural consistency
- replay rejection
- stale authority rejection
- evidence integrity

Claims become stronger through reproducibility.

---

# Reproducibility Matters

Engineering confidence increases when independent teams can reproduce results.

Validation should remain:

- repeatable
- deterministic
- documented
- independently observable

Reproducibility is more valuable than isolated demonstrations.

---

# Observable Runtime Behavior

Engineering evaluation should focus on observable properties such as:

- logical session continuity
- deterministic runtime decisions
- recovery consistency
- evidence generation
- canonical authority
- protocol invariants

Observable behavior provides measurable engineering value.

---

# Independent Verification

Engineering evidence becomes stronger when verified independently.

Independent reviewers should be able to:

- reproduce validation
- inspect evidence
- compare results
- evaluate documented methodology

Verification should not depend upon access to proprietary implementation.

---

# Documentation Supports Evidence

Engineering documentation should explain:

- validation methodology
- architectural principles
- engineering boundaries
- observable behavior
- evaluation process

Documentation strengthens reproducibility.

---

# Architectural Boundary

This document explains engineering philosophy only.

It does not describe:

- protected runtime implementation
- proprietary algorithms
- synchronization mechanisms
- transport scoring
- implementation heuristics

---

# Relationship to Other Principles

Evidence Before Claims complements:

- Engineering Confidence Is Earned
- Engineering as a Discipline
- Long-Term Engineering
- Architecture Over Complexity
- Engineering Serves the Future

Together these principles define the engineering methodology of VRP.

---

# Summary

Evidence Before Claims is a foundational engineering principle of VRP.

Engineering conclusions should be supported by reproducible validation, deterministic runtime behavior and independently verifiable evidence rather than assumption or reputation.
