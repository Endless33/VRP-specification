## Protocol Highlights

The specification defines:

- canonical session identity;
- transport-independent sessions;
- deterministic state transitions;
- authority-based validation;
- replay protection;
- failover;
- migration;
- recovery;
- evidence generation;
- protocol compliance requirements.

## Intended Audience

This specification is intended for:

- protocol implementers;
- runtime developers;
- system architects;
- validation engineers;
- independent reviewers.

## Current Status

Release Candidate

The specification is considered feature complete for the first
public review.

Editorial improvements and clarifications may still occur before
the first stable release.
