# VRP Versioning

Status: Release Candidate (v1.0.0-rc1)

## Purpose

This document defines the versioning policy for the Veil Routing
Protocol (VRP) specification and compatible implementations.

## Specification Version

The specification version identifies the published protocol
definition.

Example:

v1.0.0

## Implementation Version

Implementations maintain their own version numbers independently
of the specification.

An implementation shall identify:

- implementation name;
- implementation version;
- supported specification version.

## Compatibility

Minor revisions should preserve backward compatibility unless
explicitly documented.

Major revisions may introduce incompatible protocol changes.

## Release Stages

Development

Alpha

Beta

Release Candidate (RC)

Stable Release

## Release Candidate

A Release Candidate represents a version believed to be suitable
for release but still awaiting final validation.

The current specification status is:

v1.0.0-rc1

## Stable Release

A stable release should be published only after:

- specification review;
- implementation validation;
- compliance verification;
- pilot evaluation.

## Version Identification

Public reports should identify:

- specification version;
- implementation version;
- validation version;
- evidence version where applicable.
