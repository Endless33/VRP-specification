# 16. Node Trustlessness Model

VRP assumes that no node is trustworthy.

## Trustlessness Principles

- No node sees the full route  
- No node holds persistent state  
- No node can correlate packets  
- No node can reconstruct behavior  

## Node Capabilities

Nodes operate with:

- partial entropy  
- partial routing context  
- partial phase state  

## Node Limitations

Nodes cannot:

- identify the client  
- identify the exit  
- identify other nodes  
- reconstruct the session  

Trustlessness is not a feature.  
It is the foundation.
