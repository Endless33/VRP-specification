# 24. Glossary

Key terms used throughout the VRP specification.

### VRP  
Veil Routing Protocol — a behavioral routing model based on motion and entropy.

### Entropy  
A non-reconstructable measure of movement, variance, and unpredictability.

### Drift  
Long-term behavioral movement of a session.

### Mutation  
A routing or phase change triggered by entropy or movement.

### Phase  
A behavioral state of the protocol.

### Blind Node  
A node that sees only partial routing context.

### Veil Exit  
The final node in the routing chain.

### Movement  
Behavioral input that influences entropy and routing.

### Session  
A temporary behavioral container.

### Window  
A temporal interval where mutation may occur.
