# 04. Routing

Routing is the core behavioral mechanism of VRP.

## Routing Model

- Input: movement + entropy + phase state
- Output: routing path mutation

## Routing Rules

- Deterministic components
- Entropy-influenced components
- Phase-dependent modifiers

## Mutation

Routing paths may mutate based on:

- Entropy thresholds
- Movement patterns
- Phase transitions

This document defines routing logic at a conceptual level.
