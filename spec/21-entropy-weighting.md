# 21. Entropy Weighting (Abstract)

Entropy Weighting determines how movement, time, and events influence routing behavior.

## Weight Inputs

- movement intensity  
- movement irregularity  
- temporal variance  
- event density  
- phase context  

## Weight Outputs

- mutation probability  
- routing drift direction  
- phase transition likelihood  

## Weight Guarantees

- non-linear  
- non-predictable  
- non-reversible  
- non-reconstructable  

The exact formula is implementation-specific and private.
