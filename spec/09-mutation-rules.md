# 09. Mutation Rules

Mutation is the core behavioral mechanism of VRP.

## Mutation Triggers

- Entropy thresholds
- Movement irregularity
- Phase transitions
- Temporal variance

## Mutation Types

- Route mutation  
- Phase mutation  
- Entropy amplification  
- Event cascade mutation  

## Mutation Constraints

- Mutations must not be predictable  
- Mutations must not be reversible  
- Mutations must not be reconstructable  

Mutation is not randomness.  
Mutation is behavior.
