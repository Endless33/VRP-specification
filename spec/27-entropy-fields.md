# 27. Entropy Fields

Entropy Fields define how entropy propagates through the protocol.

## Field Types

- local entropy field  
- session entropy field  
- global entropy field  

## Field Behavior

Fields influence:

- mutation probability  
- drift direction  
- phase transitions  

## Field Guarantees

- cannot be measured directly  
- cannot be reconstructed  
- cannot be predicted  

Entropy Fields are invisible but fundamental.
