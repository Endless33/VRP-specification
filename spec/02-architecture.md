# 02. Architecture

VRP architecture consists of four primary layers:

1. **Core Engine** — processes movement, entropy, phases, and routing.
2. **Admin Layer** — provides internal control and inspection.
3. **SDK Layer** — exposes integration interfaces.
4. **Demo Layer** — visualizes protocol behavior.

## Core Concepts

- Sessions
- Phases
- Events
- Routing paths
- Entropy sources

This document defines the structural model of the protocol.
