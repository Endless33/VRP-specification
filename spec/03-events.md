# 03. Events

VRP is an event-driven protocol.  
All behavior emerges from event processing.

## Event Categories

- **Movement Events** — user movement, motion, or activity
- **Phase Events** — transitions between protocol phases
- **Routing Events** — path selection and mutation
- **System Events** — internal engine signals

## Event Properties

- Timestamp
- Entropy weight
- Phase context
- Routing impact

This document defines event semantics.
