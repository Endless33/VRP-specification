# Code of Conduct

## Purpose

The Veil Routing Protocol (VRP) community is committed to maintaining a professional, respectful and engineering-focused environment.

This repository exists to advance technical discussion around the public VRP architecture.

Professional conduct enables productive engineering collaboration.

---

# Expected Behavior

Contributors are encouraged to:

- communicate respectfully;
- discuss ideas rather than individuals;
- support technical claims with evidence;
- reference published documentation whenever possible;
- provide constructive engineering feedback;
- remain open to technical discussion.

Engineering quality benefits from professional collaboration.

---

# Unacceptable Behavior

The following behavior is not acceptable:

- personal attacks;
- harassment;
- discrimination;
- abusive language;
- trolling;
- intentional disruption;
- spam;
- misinformation presented as fact;
- publication of confidential information.

Technical disagreement is acceptable.

Personal hostility is not.

---

# Engineering Discussions

Discussions should focus on:

- architecture;
- engineering principles;
- reproducibility;
- validation;
- documentation;
- observable behavior.

Implementation details protected by design are outside the scope of public discussion.

---

# Intellectual Property

The repository intentionally separates:

- public architecture;
- protected implementation.

Contributors should respect this boundary.

Requests for confidential implementation details may be declined.

---

# Evidence-First Discussions

Technical discussions are encouraged to rely on:

- published specifications;
- RFC documents;
- ADR documents;
- engineering evidence;
- reproducible observations.

Engineering conclusions should be supported by evidence.

---

# Respect for Contributors

Every contributor deserves:

- professional communication;
- respectful technical discussion;
- recognition of contributions;
- constructive review.

Healthy engineering communities improve technology.

---

# Reporting Issues

Behavior inconsistent with this Code of Conduct may be reported through GitHub Issues or the appropriate project contact.

Reports should include sufficient information to understand the situation.

---

# Enforcement

Project maintainers may:

- request clarification;
- moderate discussions;
- close inappropriate discussions;
- remove inappropriate content;
- restrict participation when necessary.

Actions are intended to preserve a productive engineering environment.

---

# Scope

This Code of Conduct applies to:

- repository discussions;
- pull requests;
- issues;
- documentation reviews;
- engineering conversations related to the public specification.

---

# Summary

The VRP project values:

- professionalism;
- technical accuracy;
- respectful collaboration;
- engineering integrity;
- evidence-based discussion.

These principles support productive long-term engineering collaboration.
